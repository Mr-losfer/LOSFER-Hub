## 🔑 LOSFER بىر كۇنۇپكىلىق ئۇلاش

1. [https://api.losfer.cn/pc/api-list/keys/](https://api.losfer.cn/pc/api-list/keys/) ئادرېسىدىن API كۇنۇپكىڭىزنى ئېلىڭ.
2. ئەپتە **تەڭشەكلەر → LOSFER بىر كۇنۇپكىلىق ئۇلاش** نى چېكىڭ.
3. كۇنۇپكىنى كىرگۈزۈپ **ئۇلاش** نى بېسىڭ.

سىستېما ئاۋۋال كۇنۇپكىنى `https://api.losfer.cn/v1/models` ئارقىلىق دەلىللەيدۇ، ئاندىن `https://api.losfer.cn/v1` نى ئاساس قىلغان OpenAI تۈرىدىكى تەمىنلىگۈچىنى ۋە بارلىق مودېللارنى ئاپتوماتىك قوشىدۇ.

## 🧩 LOSFER ماھارەت ئامبىرى

ماھارەتلەر بېتىنىڭ ئەڭ ئۈستىدىكى **«LOSFER ماھارەت ئامبىرىنى چۈشۈرۈش»** كۇنۇپكىسىنى باسسىڭىز، [skill-sources.json](skill-sources.json) ھۆججىتىدىكى GitHub ئامبارلىرىنىڭ ھەممىسى چۈشۈرۈلۈپ، ئىچىدىكى بارلىق `SKILL.md` ماھارەتلىرى بىر قېتىمدا قوشۇلىدۇ. چۈشۈرۈش ئالدى بىلەن `gh-proxy.com` تېزلىك ۋاكالەتچىسى ئارقىلىق قىلىنىدۇ، مەغلۇپ بولسا بىۋاسىتە ئۇلىنىدۇ. بېتىدە يەنە **ھەممىنى ئېچىش / ھەممىنى تاقاش** كۇنۇپكىلىرى ۋە ھەر بىر ماھارەتنىڭ ئاچقۇچى بار.

يېڭى ئامبار قوشۇش ئۈچۈن `skill-sources.json` نىڭ `repositories` تىزىملىكىگە URL قوشۇڭ:

```json
{
  "repositories": [
    "https://github.com/NoraStory/reverse-SKILL",
    "https://github.com/owner/another-skill-repo"
  ]
}
```

ياكى ھەر بىر قۇرغا بىر URL يېزىلغان `.txt` ھۆججىتىمۇ ئىشلەيدۇ (`#` بىلەن باشلانغان قۇرلار ئىزاھات ھېسابلىنىدۇ). ھۆججەت ئوقۇلمىسا، ئەپ ئىچىگە سىڭدۈرۈلگەن سۈكۈتتىكى ئامبار ئىشلىتىلىدۇ.

## 🌐 تىل ۋە خەت نۇسخا

- **تىل**: تەڭشەكلەر → ئادەتتىكى تەڭشەكلەر → ئىنتېرفېيس تىلى (ئۇيغۇرچە / 中文 / English / سىستېما تىلى)
- **خەت نۇسخا**: تەڭشەكلەر → ئادەتتىكى تەڭشەكلەر → تىل ۋە خەت نۇسخا بېتىدە ھەر بىر خەت نۇسخىنى نۇمۇنە بىلەن كۆرۈپ تاللىيالايسىز، سۈكۈتتىكىسى **UKIJ Tuz**.

> خەت نۇسخىلار LOSFER ئۇيغۇرچە خەت نۇسخا ئامبىرىدىن ئېلىنغان، ھوقۇقى ئەسلى ئاپتورىغا تەۋە، پەقەت ئۆگىنىش ۋە ئالماشتۇرۇش ئۈچۈن.
