## 📱 نەشرى ۋە چۈشۈرۈش

بارلىق نەشرىلەر [Releases](https://github.com/Mr-losfer/LOSFER-Hub/releases) بېتىدە. ھەر قېتىم يېڭى نەشرى چىققاندا APK ھۆججىتى شۇ يەرگە يۈكلىنىدۇ، ئەپ ئىچىدىكى «يېڭىلاش» تەكشۈرۈشىمۇ مۇشۇ بەتنى ئوقۇيدۇ.

### 🆕 نەشرى 1.0.7 يېڭىلىقلىرى

ئەسلى تۈر (rikkahub) نىڭ 3.3.0 نەشرى بىلەن ماسلاشتۇرۇلدى (17 يېڭى ئۆزگىرىش):

- **تېز باشلاش بېتى** — تەمىنلىگۈچى ۋە سۈكۈتتىكى مودېلنى قەدەممۇ-قەدەم تەڭشەيدىغان يېڭى بەت. LOSFER Hub دا بۇ بەتنىڭ بىرىنچى قەدىمى بىۋاسىتە **LOSFER بىر كۇنۇپكىلىق ئۇلاش** نى ئاچىدۇ.
- **مودېل تەڭشەلمىگەن ئەسكەرتىش كارتىسى** — سۆھبەت تىزىملىكىدە كۆرسىتىلىپ، تېز باشلاش بېتىگە يېتەكلەيدۇ.
- **DeepSeek ئاۋاز** — DeepSeek نىڭ تېكىستتىن ئاۋازغا (TTS) ۋە ئاۋازدىن تېكىستكە (ASR) مۇلازىمىتى قوشۇلدى.
- **DeepSeek سۆھبەت خاتىرىسىنى ئىمپورت قىلىش** — ئېكىسپورت ZIP ھۆججىتىدىن ھەر بىر سۆھبەتنىڭ ھازىرقى تارمىقىنى ئويلىنىش جەريانى ۋە قوشۇمچە ھۆججەتلىرى بىلەن بىرگە ئىمپورت قىلىدۇ.
- **ئىش بوشلۇقى سىرتقى ساقلاش** — ئۈسكۈنىنىڭ ھەمبەھرىلەنگەن ساقلاش بوشلۇقىدىكى قىسقۇچلارنى Rootfs غا باغلايدۇ.
- **پاراگراف بويىچە پارچىلاش** — ياردەمچىنىڭ جاۋابىنى ھەر بىر پاراگراف ئايرىم كۆپچە سۆھبەت كۆرۈنۈشىدە كۆرسىتىش (كۆرسىتىش تەڭشىكىدە).
- **سۆھبەت خەرىتىسىدە يىغىش نۇقتىسى** — مەزمۇن ئاپتوماتىك يىغىلغان ئورۇن بەلگىلىنىدۇ.
- **بىخەتەر ھالەت** — بەك چوڭ تەڭشەك سانلىق مەلۇماتىنى تازىلاش ئىقتىدارى قوشۇلدى.
- **يېڭىلانما چۈشۈرۈش** — VPN ئېچىلغاندا يېڭىلانما ھۆججىتى چۈشۈرۈلمەسلىك مەسىلىسى تۈزىتىلدى.
- **DeepSeek ئىمپورتى** — Android 9/10 دا `#` بار ھۆججەت ئىسىملىك قوشۇمچىنى ئىمپورت قىلغاندا ئەپ توختاپ قېلىش مەسىلىسى تۈزىتىلدى.
- **ئىچكى ياردەمچىنى ئۆچۈرۈش** — ئىچكى قۇرۇلغان ياردەمچىنى ئۆچۈرگىلى بولىدۇ (كەم دېگەندە بىرى ساقلىنىدۇ).
- **ئۇيغۇرچە تەرجىمە تولۇقلاندى** — يېڭى قوشۇلغان 75 تېكىستنىڭ ھەممىسى ئۇيغۇرچە تەرجىمە قىلىندى، ئىنتېرفېيىس تىلى ئۇيغۇرچە بولغاندا پۈتۈن ئەپ RTL يۆنىلىشتە كۆرسىتىلىدۇ.

## 🔑 LOSFER بىر كۇنۇپكىلىق ئۇلاش

1. [https://api.losfer.cn/pc/api-list/keys/](https://api.losfer.cn/pc/api-list/keys/) ئادرېسىدىن API كۇنۇپكىڭىزنى ئېلىڭ.
2. ئەپتە **تەڭشەكلەر → LOSFER بىر كۇنۇپكىلىق ئۇلاش** نى چېكىڭ.
3. كۇنۇپكىنى كىرگۈزۈپ **ئۇلاش** نى بېسىڭ.

سىستېما ئاۋۋال كۇنۇپكىنى `https://api.losfer.cn/v1/models` ئارقىلىق دەلىللەيدۇ، ئاندىن `https://api.losfer.cn/v1` نى ئاساس قىلغان OpenAI تۈرىدىكى تەمىنلىگۈچىنى ۋە بارلىق مودېللارنى ئاپتوماتىك قوشىدۇ.

## 🧩 LOSFER ماھارەت ئامبىرى

ماھارەتلەر بېتىنىڭ ئەڭ ئۈستىدىكى **«LOSFER ماھارەت ئامبىرىنى چۈشۈرۈش»** كۇنۇپكىسىنى باسسىڭىز، [skill-sources.json](skill-sources.json) ھۆججىتىدىكى GitHub ئامبارلىرىنىڭ ھەممىسى چۈشۈرۈلۈپ، ئىچىدىكى بارلىق `SKILL.md` ماھارەتلىرى بىر قېتىمدا قوشۇلىدۇ. چۈشۈرۈش ئالدى بىلەن `gh-proxy.com` تېزلىك ۋاكالەتچىسى ئارقىلىق قىلىنىدۇ، مەغلۇپ بولسا بىۋاسىتە ئۇلىنىدۇ. بېتىدە يەنە **ھەممىنى ئېچىش / ھەممىنى تاقاش** كۇنۇپكىلىرى ۋە ھەر بىر ماھارەتنىڭ ئاچقۇچى بار.

يېڭى ئامبار قوشۇش ئۈچۈن `skill-sources.json` نىڭ `repositories` تىزىملىكىگە URL قوشۇڭ:

```json
{
  "repositories": [
    "https://github.com/NoraStory/reverse-SKILL",
    "https://github.com/owner/another-skill-repo"
  ]
}
```

ياكى ھەر بىر قۇرغا بىر URL يېزىلغان `.txt` ھۆججىتىمۇ ئىشلەيدۇ (`#` بىلەن باشلانغان قۇرلار ئىزاھات ھېسابلىنىدۇ). ھۆججەت ئوقۇلمىسا، ئەپ ئىچىگە سىڭدۈرۈلگەن سۈكۈتتىكى ئامبار ئىشلىتىلىدۇ.

## 🌐 تىل ۋە خەت نۇسخا

- **تىل**: تەڭشەكلەر → ئادەتتىكى تەڭشەكلەر → ئىنتېرفېيس تىلى (ئۇيغۇرچە / 中文 / English / سىستېما تىلى)
- **خەت نۇسخا**: تەڭشەكلەر → ئادەتتىكى تەڭشەكلەر → تىل ۋە خەت نۇسخا بېتىدە ھەر بىر خەت نۇسخىنى نۇمۇنە بىلەن كۆرۈپ تاللىيالايسىز، سۈكۈتتىكىسى **UKIJ Tuz**.

> خەت نۇسخىلار LOSFER ئۇيغۇرچە خەت نۇسخا ئامبىرىدىن ئېلىنغان، ھوقۇقى ئەسلى ئاپتورىغا تەۋە، پەقەت ئۆگىنىش ۋە ئالماشتۇرۇش ئۈچۈن.
