## 📱 نەشرى ۋە چۈشۈرۈش

بارلىق نەشرىلەر [Releases](https://github.com/Mr-losfer/LOSFER-Hub/releases) بېتىدە. ھەر قېتىم يېڭى نەشرى چىققاندا APK ھۆججىتى شۇ يەرگە يۈكلىنىدۇ، ئەپ ئىچىدىكى «يېڭىلاش» تەكشۈرۈشىمۇ مۇشۇ بەتنى ئوقۇيدۇ.

## ✨ ئالاھىدىلىكلىرى

| ئىقتىدار | چۈشەندۈرۈش |
|---|---|
| 🌍 ئۇيغۇرچە ئىنتېرفېيس | ئۇيغۇرچە تاللانغاندا پۈتۈن ئەپ ئاپتوماتىك **RTL** (ئوڭدىن سولغا) يۆنىلىشتە كۆرسىتىلىدۇ |
| 🎉 تۇنجى قېتىم ئېچىلغاندا تىل تاللاش | iOS نىڭ قارشى ئېلىش بېتىگە ئوخشاش، ئاۋۋال تىل تاللىنىدۇ |
| 🔤 كۆپ خىل ئۇيغۇرچە خەت نۇسخا | ALKATIP Asliya (سۈكۈتتىكى) / Basma / Kitab / AlpsoftBasma-b / UKIJ Tuz / UUS UN Asliya، نۇمۇنە بىلەن كۆرۈپ تاللايسىز |
| 🔑 LOSFER بىر كۇنۇپكىلىق ئۇلاش | API كۇنۇپكىسىنى كىرگۈزسىڭىزلا، تەمىنلىگۈچى ۋە بارلىق مودېللار ئاپتوماتىك قوشۇلىدۇ |
| 🧠 كۆپ تەمىنلىگۈچى | OpenAI، Gemini، Claude، LOSFER قاتارلىق مۇلازىمەتلەرنى قوللايدۇ |
| 🎨 Material 3 Expressive | زامانىۋى كۆرۈنۈش ۋە قاراڭغۇ ئەھۋال |

## 🔑 LOSFER بىر كۇنۇپكىلىق ئۇلاش

1. [https://api.losfer.cn/pc/api-list/keys/](https://api.losfer.cn/pc/api-list/keys/) ئادرېسىدىن API كۇنۇپكىڭىزنى ئېلىڭ.
2. ئەپتە **تەڭشەكلەر → LOSFER بىر كۇنۇپكىلىق ئۇلاش** نى چېكىڭ.
3. كۇنۇپكىنى كىرگۈزۈپ **ئۇلاش** نى بېسىڭ.

سىستېما ئاۋۋال كۇنۇپكىنى `https://api.losfer.cn/v1/models` ئارقىلىق دەلىللەيدۇ، ئاندىن `https://api.losfer.cn/v1` نى ئاساس قىلغان OpenAI تۈرىدىكى تەمىنلىگۈچىنى ۋە بارلىق مودېللارنى ئاپتوماتىك قوشىدۇ.

## 🌐 تىل ۋە خەت نۇسخا

- **تىل**: تەڭشەكلەر → ئادەتتىكى تەڭشەكلەر → ئىنتېرفېيس تىلى (ئۇيغۇرچە / 中文 / English / سىستېما تىلى)
- **خەت نۇسخا**: تەڭشەكلەر → ئادەتتىكى تەڭشەكلەر → تىل ۋە خەت نۇسخا بېتىدە ھەر بىر خەت نۇسخىنى نۇمۇنە بىلەن كۆرۈپ تاللىيالايسىز، سۈكۈتتىكىسى **ALKATIP Asliya**.

> خەت نۇسخىلار LOSFER ئۇيغۇرچە خەت نۇسخا ئامبىرىدىن ئېلىنغان، ھوقۇقى ئەسلى ئاپتورىغا تەۋە، پەقەت ئۆگىنىش ۋە ئالماشتۇرۇش ئۈچۈن.

## 🛠 قۇرۇش

```bash
# JDK 21 ۋە Android SDK (API 37) كېرەك
./gradlew :app:assembleGithubRelease
```

چىققان ھۆججەت: `app/build/outputs/apk/github/release/`
